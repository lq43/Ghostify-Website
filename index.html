Developer Overview

What is Ghostify?

Ghostify is an Android location simulation and developer QA utility designed exclusively for testing and debugging location-aware mobile applications.

Official Informational & Presentation Website

This website serves strictly as the official presentation, documentation, and contact portal for the Ghostify project. This website does not implement GPS spoofing, fake GPS, location simulation, mock locations, or any functionality that changes a device's location. Ghostify is intended exclusively for software developers and QA engineers testing their own location-aware Android applications in controlled environments.

Built for QA & Engineers

Accelerate QA workflows for navigation apps, delivery tracking, and geofencing without having to travel physically.

100% Local & Offline

No cloud accounts, telemetry trackers, or external servers. All coordinates run strictly on the test device via Android APIs.

Transparent Open Source

Completely open source codebase on GitHub. Inspect the Kotlin logic, submit PRs, and audit the code anytime.

Core Capabilities

Engineering Features

Purpose-built tools for testing edge cases, boundary transitions, and location accuracy.

Android Mock Provider

Direct integration with native Android LocationManager.setTestProviderLocation for high fidelity simulation.

Virtual Joystick & Routes

Navigate test coordinates smoothly in real time with variable speed, waypoint paths, and realistic bearing angles.

Geofence Boundary Testing

Test entry, exit, and dwell triggers around virtual perimeters to verify background alert handlers and geocaching logic.

Elevation & Sensor Jitter

Simulate realistic altitude changes and subtle natural GPS coordinate noise to challenge app smoothing algorithms.

QA Velocity Presets

Quickly switch simulation velocities between Walking (5 km/h), Cycling (20 km/h), Driving (65 km/h), and High-Speed Train.

Floating HUD Overlay

Adjust coordinates while actively interacting with the target application without needing to switch back and forth.
